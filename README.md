# Brand et al. 2026

Analysis code for Brand et al. 2026.

## Scripts

- `Brand_et_al_26_flytracker_postProcessing.m` – Script processes tracking results from flyTracker for analysis
- `Brand_et_al_26_tracking_data_analysis_plotting.m` – Script used to analyze and plot behavioral tracking data
- `Brand_et_al_26_gridAssay_data_analysis_plotting.m` – Script used to analyze and plot grid assay experiments
- `Brand_et_al_26_functional_imaging_postProcessing.m` – Script used to process virmen tracking data from functional imaging experiments
- `Brand_et_al_26_computeTI.m` – Function required to run `Brand_et_al_26_functional_imaging_postProcessing.m`
- `Brand_et_al_26_functional_imaging_plotting.m` – Script used to analyze and plot functional imaging experiments
